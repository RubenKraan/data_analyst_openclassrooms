Projet 13 – Créez votre portfolio de professionnel de la data

Durée : 60 heures – Projet achevé

Contexte

Dans ce projet, j’ai conçu un portfolio complet pour répondre à une demande client simulée par Aéroworld. L’objectif était de structurer mes compétences, mes livrables et mes outils dans une interface claire et professionnelle.

Ce que j’ai réalisé

  • Carte mentale pour organiser les éléments du portfolio
  • Analyse du besoin client et rédaction du cahier des charges
  • Diagramme de Gantt pour planifier les étapes du projet
  • Création des tableaux de bord interactifs sur power bi
  • Réalisation d’une vidéo de présentation (Loom)
  • Documentation technique et pédagogique
  • Intégration finale dans un portfolio web (GitHub Pages)

Compétences acquises

  • Structuration d’un portfolio professionnel
  • Gestion de projet : analyse, planification, livrables
  • Data storytelling et visualisation avec power bi
  • Communication pédagogique via vidéo et documentation
  • Veille technologique et synthèse d’informations

Outils & technologies

  • Figma, Miro (mock-up & design)
  • power bi
  • Loom (présentation vidéo)
  • GitHub Pages (hébergement du portfolio)
  • Feedly (veille technologique)

Livrables

  • Carte mentale (PDF)
  • Cahier des charges & Gantt
  • Mock-ups des dashboards
  • Tableaux de bord interactifs
  • Vidéo de présentation
  • Documentation complète
  • Portfolio final en ligne
